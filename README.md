
# CSS Changer Application

A simple interactive web application built with HTML, CSS, and JavaScript.

## Features

- Change the base color
- Adjust image width
- Modify border radius
- Control image padding
- Adjust blur effects
- Update CSS variables dynamically

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Use the controls to change the image appearance.
